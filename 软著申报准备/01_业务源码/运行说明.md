# 工业裂缝检测离线版 V1.0 · 运行说明

这是独立整理的业务程序目录。原项目不被修改；本目录程序窗口标题为“工业裂缝检测离线版 V1.0”，内部版本 `1.0.0`。

## 在当前电脑启动并截图

1. 在本文件所在的 `01_业务源码` 文件夹中打开 PowerShell。
2. 编辑同目录 `inspection_config.json` 的 `weights`，填写你有权使用的裂缝权重路径。
3. 当前项目已有权重可在文件选择器中选择原项目 `runs/detect/steel_crack_detect_v8n_0808_1850/weights/best.pt`；也可将配置写为 `../../runs/detect/steel_crack_detect_v8n_0808_1850/weights/best.pt`。此路径仅适用于本目录保持在原项目内时。
4. 执行下面命令，使用原项目已安装好的 Python 环境：

```powershell
..\..\.venv\Scripts\python.exe app.py
```

本包默认配置使用 `weights/best.pt`，仓库不包含此文件；启动界面后也可点击“选择模型”指定已有权重。没有有效模型时无法执行检测。

`output` 默认是本目录下 `inspection_data`，因此不会混入原项目检测记录。启动后按截图清单录入自有图片和测试工件编号。

## 独立复制到其他电脑

在本目录安装依赖并准备授权模型：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Python 建议 3.11–3.13，当前验证环境为 Windows / CPU；安装时需要网络。准备好依赖和模型后可离线检测。没有随附安装器或保证所有电脑均兼容。

模型须为单一 `crack` 类别的 YOLO 检测/分割模型。只加载可信权重。申请包不附模型、数据、检测历史或虚拟环境。
