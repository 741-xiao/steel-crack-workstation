# 工业裂缝检测离线版 V1.0 用户操作手册

状态：待补真实运行截图的说明书草稿。内部版本 `1.0.0`。本手册针对申报目录内的程序，标题和截图不应混用原项目 2.1.0。

## 1. 软件用途与运行条件

软件用于离线图片、视频及文件夹的裂缝辅助筛查，记录机器预测，并支持人工复核和结果追溯。它不直接判断工件是否符合质量标准，不提供毫米级尺寸测量或 PLC/MES 对接。

运行环境为 Windows、Python 3.11–3.13 及依赖清单中的软件包；需准备可信且有权使用的单类别 `crack` 模型。支持 CPU 推理，处理速度随硬件、图像尺寸和数量变化。

安装依赖和配置模型的方法见 `01_业务源码/运行说明.md`。运行后生成的数据库和图片位于配置的结果目录。

## 2. 打开软件

运行申报目录中的 `app.py`。窗口标题应显示“工业裂缝检测离线版 V1.0”。主要区域包括本地模型、检测输入、批次/工件编号、置信度阈值、控制按钮、图片预览、详情、历史记录和人工复核区。

## 3. 检测一张图片

1. 点击“选择模型”，选择可信的裂缝模型。
2. 点击“选择图片 / 视频”，选择一张自有或有权使用的图片。
3. 在“批次 / 工件编号”输入 `演示工件001` 等易识别编号。
4. 设置置信度阈值；首次演示可保持默认 0.25，该值不是现场验收阈值。
5. 点击“开始检测”，等待结果写入。
6. 查看预览和状态栏，再在历史表中选择该记录查看详情。

【待插图 S02：输入参数设置。待插图 S03：实际图片检测结果。】

机器结果含义：疑似裂缝表示模型检出目标，未检出不代表合格，处理失败表示该项没有获得有效检测结果。框上的评分是模型置信度，不是统计意义上的整体准确率。

## 4. 批量图片与视频

点击“选择文件夹”可处理其中支持的图片和视频；支持的文件类型以文件选择器为准。视频按 `video_stride` 设置抽帧。输入目录与输出目录不可相互包含，避免重复扫描生成文件。

任务运行时显示已处理数量、疑似裂缝数量和失败数量。需要中止时点击“停止”；程序在当前帧处理、保存完成后停止，界面恢复可操作状态。

【待插图 S04：批量/视频任务运行或完成状态；如尚未演示，保留待补说明。】

## 5. 查询历史和原图

从批次下拉框选择指定批次，或选择全部批次；可进一步按复核状态筛选。历史表显示最近 200 条匹配记录，CSV 和样本导出不受该显示数量限制。批次选择列表显示最近 100 个批次。

点击历史行查看图片、检测坐标、模型指纹和参数。勾选“查看原图（便于复核）”切换到未画框图像。结果没有保存图片或图片已经缺失时，界面提示无图，不能据此认定无裂缝。

【待插图 S05：批次筛选和原图查看。】

## 6. 保存人工复核

1. 等待检测任务结束，选择待复核记录。
2. 检查图片与机器结果，输入实际复核人姓名。
3. 选择“人工确认有裂缝”“人工确认无裂缝”或“待进一步复查”。
4. 在“复核依据”写明理由，点击“保存人工复核”。

复核结论针对整张图片，不表示所有预测框准确。机器结果仍保留；人工结论有独立记录。无裂缝判断不等于工件符合所有质量标准。复核姓名是手工记录，没有登录身份认证。

【待插图 S06：填写复核信息。待插图 S07：保存后的人工复核状态。】

需要修订时重新选中记录，填写新结论与理由再保存。详情中的 `review_history` 保留历次意见，不覆盖旧记录。若另一窗口已更新，提交会提示刷新后重新确认。处理失败项不能直接复核成无裂缝，应先重新检测。

【待插图 S08：同一条记录的两次复核历史；演示修订应写清演示原因。】

## 7. 导出 CSV

选择批次与复核状态，点击“导出 CSV”，指定文件名。导出的记录含机器结果、最新复核结论、复核人、依据及时间。可用支持 UTF-8 的表格软件打开；导出对可能作为表格公式解释的文本作转义。

【待插图 S09：导出成功提示和 CSV 表头、示例记录。】

## 8. 回收待标注样本

点击“导出复核样本 ZIP”，选择保存位置。系统仅导出当前筛选下已复核记录；没有可用记录时提示先完成复核。ZIP 包含说明、数量汇总及每条记录的预测、参数、模型信息、复核历史；有保存原图时包含原图。

缺少原图会明确计数。包内判断分歧有助于回收疑似漏检和误报，但不是精确率、召回率或 mAP 统计。ZIP 不是可直接训练的数据集，仍需人工补框、修框和标注复查。

## 9. 异常处理、退出与维护

| 现象 | 处理方式 |
| --- | --- |
| 找不到模型 | 检查本地文件路径；克隆包不附权重 |
| 模型类别不匹配 | 使用仅包含 `crack` 类别的检测/分割模型 |
| 图片读取失败 | 另存为到稳定目录，检查格式与文件是否损坏 |
| 复核保存失败 | 填写姓名、结论与依据；版本冲突则刷新并查看最新意见 |
| 没有已复核样本 | 保存复核或调整筛选条件 |
| 磁盘空间不足 | 停止任务，备份并按需归档；不要运行中手动删数据库文件 |
| 强制结束后批次仍为运行中 | 该批次未正常结束，不能当作全部完成；保留记录并重新执行必要输入 |

正常关闭运行中的窗口时，程序请求停止，等待当前操作完成后退出。定期在关闭程序后备份整个结果目录，包含数据库与图片。单独复制 CSV 不能替代完整备份。
